# 操作面交互（方案 A）

## Goal

顶摄笔记本训练改为**机身操作面**模型：手在画面上的位置对应机身正面热区，不再假装自由 3D 深度抓取。

## Decisions

| ID | Decision |
|----|----------|
| D-model | 操作面（分层 Z），非自由工作区 |
| D-depth | 交互点 Z = 当前 SOP 热区所在层；放弃 palm-size 深度参与命中 |
| D-focus | 一步一主热区（开卡扣可左右同时亮） |
| D-act | 瞄准球进入热区短停即操作；握合不参与「触发」 |
| D-carry | 取下后零件跟手；移到左侧或张开手入栏 |
| D-precision | 不做指尖级螺母精度；热区要大、要贴机身正面 |

## Contract（交互契约）

1. **操作面**：机身前有固定深度层（前/中/深）。当前 SOP 零件决定激活哪一层。
2. **手 → 面**：顶摄只可靠提供画面 XY；交互点 = `(手XY, 当前层 Z)`。青色球表示「手上的操作点在机身面上的投影」，不是手套指尖真值。
3. **热区**：仅当前 SOP 零件可交互。命中用面上距离（Z 对齐后 ≈ XY）。
4. **触发**：球进入热区**内圈**并持续约 1 秒 → 执行（开卡扣 / 拆下 / 拧螺母）。外圈只引导瞄准，不触发。
5. **携带**：跟手移动；移到画面左侧或张开手 → 入栏 / 松手回装。
6. **禁止**：用估计深度抢命中；非 SOP 零件抢高亮；握合阈值决定能否拆装。

## Acceptance
