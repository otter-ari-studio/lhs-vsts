# PRD: 大家电虚拟仿真训练平台完整方案重设计

## Goal

推倒重做「在线大家电虚拟仿真训练平台」：学员**只打开网页并授权摄像头**，在浏览器内完成油烟机拆洗训练（拆装 + 轻量清洁示意），获得可理解的步骤引导、过程反馈与是否合格结论。本任务交付完整方案（本 PRD、`design.md`、`implement.md`）；编码在用户批准后由子任务执行。

## Background

### 现状问题（旧栈事实）

旧实现为 Python MediaPipe → 本机 WebSocket → React/Three 方块场景 + 腕距捏合拆装。可联调，但观感像玩具、交互不稳、无清洁教学闭环、且非真正在线单页产品。详见仓库 `README.md` 与 `.trellis/tasks/09-25-migrate-unity-to-threejs-mvp*`。

### 用户已锁定方向

整体推倒重做；动捕进浏览器；首期做可训最小闭环而非平台壳。

## Decisions（全部锁定）

| ID | Decision |
|----|----------|
| D-arch | 纯浏览器动捕；无 Python/WS 运行时 |
| D-rewrite | Greenfield 应用；旧栈不长期双维护（可短暂停 `legacy/` 后删除） |
| D-scope-mvp | 单机型油烟机可训闭环：追踪 + 中保真机型 + 可靠拆装 + 步骤条 + 轻量清洁；多机型/账号后置 |
| D-asset | 中保真程序化/Kitbash；`partId`+锚点契约稳定，正式 GLTF 可热替换 |
| D-device | 默认笔记本顶摄、端坐桌前；首期不做平板/外接工位预设 |
| D-pedagogy | 完成全部必选步骤即合格；过程扣分与错因仅反馈，不挡合格；未完成步骤 = 不合格 |
| D-clean-ux | 清洁热点停留约 1.5s 完成；同时提供「标记已清洁」UI 兜底 |

## Requirements

### 产品（首期）

- **R1** 单一 Web 应用开训：摄像头权限 → 手部追踪 → 训练场景；无 Python/本机 WS。
- **R2** 双手 21 点（或等价）驱动虚拟手；笔记本顶摄标定引导 + 一键重标定；短暂丢检有保持/提示策略。
- **R3** 油烟机与可交互零件为中保真可辨识网格（非旧方块玩具主路径）；渲染实现与机型逻辑解耦。
- **R4** 拆装：接近高亮、可交互提示、捏合抓取/跟手、松手吸附回装；非法顺序 tip + 扣分（不挡通关）。
- **R5** 卡扣开合；螺母首期可用「捏合停留拧下/拧上」简化，文案提示反牙方向（精细旋转手势后置）。
- **R6** 清洁：零件进入可清洁态后显示热点；手停留达标或点 UI 兜底 → 标记已清洁；计入必选步骤。
- **R7** 步骤条：当前步、已完成、锁定原因；与机型 SOP 一致。
- **R8** 结束页：合格/不合格（步骤完成度）+ 得分 + 错因列表；支持再训。
- **R9** 机型数据契约含零件、锚点、prereqs、snap、tips、清洁点、评分常量；去掉 Unity `prefabPath` 运行时依赖。

### 规划（本任务）

- **R-P1** `design.md` 描述目标架构、模块边界、数据流、退役图与权衡。
- **R-P2** `implement.md` 描述分阶段清单、子任务映射、验证命令与风险点。

## Out of Scope

**首期不做：** 分数线考核模式、外接摄像头第二预设、平板/手机优化、量产写实 GLTF、多机型目录、账号/LMS、流体清洗物理、精细螺母力矩手势、VR/全身动捕、维持旧 Python WS 兼容。

**本规划任务不做：** 大规模编码与最终资产制作。

## Technical Notes（摘要，细节见 design.md）

- 首期 SOP 以现有 `range_hood_generic` 零件图为起点，并插入各可清洁零件的 `clean_*` 必选步。
